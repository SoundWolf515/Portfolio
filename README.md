# Portfolio V 0.1 - Wolf Shadowflame

Personal website built with HTML, CSS and JavaScript vanilla.

## Structure

- `css/` - separate styles per section
- `js/` - component logic
- `data/projects.json` - project data source
- `assets/` - images and icons

## Technical decisions
- No frameworks, to keep the project lightweight and scalable
- Projects loaded from JSON for easy updates
- Responsive with a main breakpoint at 768px

## How to run it locally?
Open `index.html` directly in the browser or use Live Server in VSCode.
